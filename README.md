# Дистанционные уроки RYTP

Объединяйте картинки в слайдшоу с переходами и нейроозвучкой!

Первоначальная идея и реализация принадлежит DominoBoy.
Он навайбкодил однофайловый скрипт, который я разбил на модули и переделал в воспроизводимый проект.

## Требования перед запуском

У вас должны быть установлены:

- [ffmpeg](https://ffmpeg.org/) — утилита для обработки мультимедиа
- [uv](https://docs.astral.sh/uv) — менеджер проектов на Python (устанавливается одной командой)

Проект использует PaddleOCR для распознавания текста на картинках и XTTS для клонирования голоса и озвучки текста.
Их **не нужно** устанавливать отдельно, они скачиваются как зависимости проекта.

Также убедитесь, что у вас есть следующие файлы:

- картинки для слайдшоу
- `voice.wav` — клонируемый голос, которым будет озвучен текст на картинках
- `Музыка.mp3` — фоновая музыка

## Как пользоваться

1. Клонируйте репозиторий.
    - Самый простой способ: скачайте архив через "Code > Dowload ZIP" и распакуйте его.
    - Через `git`:
    ```
    git clone https://github.com/RomanPro100/remote-rytp-lesson
    ```
2. Перенесите в папку проекта картинки, `voice.wav` и `Музыка.mp3` — они должны быть на одном уровне с файлом `main.py`.
3. Откройте в папке проекта терминал — убедитесь, что она является рабочей директорией в терминале.
4. Запустите скрипт:
    ```
    uv run main.py
    ```
    - При первом запуске скачаются нужная версия Python, пакеты и модели.

Скрипт вернёт, помимо прочего, видео с получившимся слайдшоу.

> Совет: Параметры слайдшоу и работы скрипта заданы в коде, можете изменять их перед запуском.
